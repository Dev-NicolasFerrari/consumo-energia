# 📋 Fichário DS - Calculadora de consumo elétrico inteligente

### 📝 Este projeto é uma atividade escolar.  
### 🖥️ O programa solicita o **tipo de aparelho**, sua **voltagem** e o **tempo estimado de uso diário**, calcula o **consumo mensal** estimado e também o valor estimado da **fatura mensal**.
---
## 🧮 Fórmulas utilizadas para os cálculos:
### ⚡ Consumo mensal: ("potência do aparelho" x "tempo de consumo" x 30) / 100  
### 🧾 Fatura mensal: "consumo mensal" * R$0,75
